# Disney+ Content-Based Recommendation System

## Overview

Developed a recommendation engine that suggests similar Disney+ titles using natural language processing techniques.

## Key Highlights

* Implemented TF-IDF vectorization for text representation
* Used cosine similarity to compute content similarity
* Built a recommendation function for top-N suggestions

## Example

```python
recommend("Frozen")
```

## Tech Stack

* Python
* Pandas
* Scikit-learn

## Dataset

Disney+ titles dataset (~1450 records)
